# Relay binding for the installed subagent flow

Root [AGENTS](../../AGENTS.md#shared-subagent-workflow) explicitly adopts
`org.jresearch.ai/landscape-subagents@1.0.2` for Relay development. Its complete
[installed policy](../../vibevm/vibedeps/org.jresearch.ai.landscape-subagents/1.0.2/vibevm/vibespecs/protocols/subagents.md)
is the reusable owner; this file is local routing and migration accounting,
not another maintained copy. Read the policy before substantial work when
Subagents is On and the Task and runtime permit delegation. Unrelated sessions
and prohibited delegation skip the detailed policy.

## Relay-owned boundaries

The [execution policy](../execution-policy.md) and admitted Task/CR retain scope,
profile, permission, protected operations and evidence authority. Keep the
admitted parent profile unchanged; child choices remain within consumer/task
permissions and available runtime controls. Requested profiles are not actual
runtime telemetry. No recommendation expands an allowlist or substitutes a
locked profile. Preserve owner, worker, trusted Writer and independent Reviewer
separation: helper checks supply implementation evidence, never native
independent acceptance. No nested Relay workers, execution fan-out, publication,
credentials or production authority follows from adoption.

Use the reviewed lock and installed snapshot throughout an admitted Task.
[Version maintenance](../vibevm.md#landscape-flows-and-local-adoption) deliberately
updates source-controlled dependencies between tasks; no moving upstream
`SUBAGENTS.md` read is required. Installation alone does not adopt policy, alter
client instructions or guarantee useful delegation. Candidate AGENTS, boot and
package routes remain proposals under the independently frozen accepted source.
