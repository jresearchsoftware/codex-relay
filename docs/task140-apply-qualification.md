verifier and configuration canonicalization in an isolated process before

Regression coverage reproduces the previous concurrency bytes and manifest,
rejects them before any gate mutation, and accepts target bytes independently
of the installed renderer. Malformed inputs and private target diagnostics
remain fixed public failures.

`workflow-project` from a clean checkout of accepted `f3230e00...`, using the
actual installed production configuration read-only. They are proposals for
ordinary review and merge. The templates are unchanged by this correction.

gate edits, force publication and automatic rollback are not remedies. This
Task execution does not perform that production recovery.
