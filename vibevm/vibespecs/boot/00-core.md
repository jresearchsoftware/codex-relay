VibeVM block. Apply that policy once if this client has not already loaded it;
do not traverse the AGENTS/INDEX route again. Keep existing client instruction
precedence and the admitted Issue/Task Request/CR authority unchanged.

to the admitted work. Preserve owner, worker, Writer and independent Reviewer
responsibilities and all existing protected boundaries. File routing grants no
execution, publication, approval, deployment, merge or closure authority.

implementation rule, session-time command or persistent task state.
