# Local routing conventions

Keep component details in their existing canonical documents and load them just
in time. Consult `docs/vibevm.md` when maintaining this route, not at every
session startup. Ordinary work reads committed files offline and needs no VibeVM
executable, registry, cache or extra owner action.

The pinned development-governance 2.1.0 pointer routes relevant controls and
requirement-origin decisions to the committed shared procedures adopted in
human-owned `AGENTS.md`. Read their full content only when relevant, together
with the Relay bindings at
`docs/execution-policy.md#proportional-controls-and-operator-usability`.
Relay's full material contract-change gate stays local. Only proportional-controls
and requirement-authority are adopted. Bundled task-handoff, package-versioning,
self-adoption and GitHub repository governance remain references; their presence
does not activate new approval, routing or settings behavior. See
`docs/relay-guidance-ownership.md` when assessing those boundaries.
