# Landscape subagent flow

This package is passive. Installation, discovery or reading this boot does not
adopt its policy or authorize delegation. Skip its detail unless the consumer's
applicable instructions explicitly adopt this flow. Existing adequate
integrations need no additional copy or adoption.

When explicitly adopted, before substantial work with Subagents On and delegation
permitted by the task and runtime, read the full
[subagent policy](../protocols/subagents.md). It requests useful proactive
delegation at every supported parent effort, including non-Ultra levels, with
no helper quota. Select each child's model and effort for its bounded assignment
within the consumer's allowed choices. Preserve Subagents Off, higher-priority
restrictions, the parent's profile and consumer review/publication authority.

For adoption or update assessment only, consult the
[adoption guide](../guides/adoption.md) and
[version contract and provenance](../../../README.md). No boot command,
configuration change or runtime fetch is required. Keep the adopted installed
version stable throughout an admitted task; Relay gains no model-routing role.
