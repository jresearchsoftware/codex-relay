# Landscape model guidance 1.0.3

`org.jresearch.ai/landscape-model-guidance@1.0.3` is a passive VibeVM
`flow` for choosing general model and reasoning-effort profiles. Public sources
were checked on **2026-11-02**, incorporating the October 24 refresh. This patch
refreshes dated qualitative evidence for Coding Agent Index v2.0, Intelligence
Index v5.0, Terra and provider/client updates. The general profiles,
assignment recommendations and consumer authority remain unchanged.

## Reading route

The compact [boot](vibevm/vibespecs/boot/landscape-model-guidance.md) conditionally
routes selection work to the complete
[selection guidance](vibevm/vibespecs/protocols/model-selection.md).
The [dated evidence](vibevm/vibespecs/reference/evidence.md) explains the
recommendations and links directly to public provider and benchmark sources.
Installed reading is self-contained; following citations is optional.

## Frozen compatibility contract

Version `1.0.3`, epoch `1`, format `simple` preserves the passive reading route,
explicit model/effort recommendations and consumer authority boundary. It
contains authored interpretation and dated source references. There is no
supported machine-readable benchmark interface. The six-file public inventory
and qualitative-only distribution boundary are unchanged from 1.0.2. Current
coding evidence does not measure Sol/xhigh; retaining the default is not a new
experimental validation or an instruction to replace it with max or Terra.
`frozen = true` declares the intended snapshot contract; it does not prove a
published tag exists or that hosting enforces immutability.

This version does not follow moving recommendations, discover account access,
choose a runtime model, configure a client, launch helpers or change an admitted
task. It has no dependencies, Skills, tools, hooks, capabilities or network
service. `publish = false` grants no publication permission. Source acceptance,
publication and consumer adoption remain separate.

Consumers own adoption, allowed models, risk/cost constraints, task overrides
and the explicit model/effort written into their task authority. Availability
must be checked in the actual client under that authority. An unavailable
recommendation is not permission to substitute an admitted profile or obtain
credentials. Installation is availability, not acceptance of every
recommendation or permission for external actions.

## Relationship to subagent guidance

The assignment matrix is included as model-selection advice. This package has
no dependency on a delegation package and adopts no delegation workflow. A
consumer's independently adopted policy and runtime constraints decide whether
helpers may run. No helper count is promised.

## Qualification and limits

Producer checks verify the exact package inventory, retained recommendation
semantics, passive manifest, relative links, public citation allowlist and
absence of private provenance or redistributed benchmark data. These checks
are producer tooling and do not travel with this guidance flow.

For a local inspection, verify the `vibe.toml` identity and boot route, follow
the relative Markdown links and inspect the six authored files: this README,
LICENSE, manifest, boot, selection guidance and evidence note. Reading or
installing them does not prove actual account eligibility, runtime behavior,
consumer adoption or a published release.
