## Why the profile choices remain

Artificial Analysis's [Codex comparison](https://artificialanalysis.ai/agents/coding-agents/comparisons/codex-vs-muse-code)
now reports Coding Agent Index **v2.0**. **Sol/xhigh is absent** from the checked
table, as are Sol medium/high and Luna/high. The historical v1.5 comparison
favoring Sol/xhigh over Sol/max belongs to the earlier evidence generation.
Current v2.0 evidence neither reconfirms nor reverses that comparison. Max results do not
measure xhigh. Retaining the accepted default pending comparable coding or
consumer-task evidence is project judgment, not fresh experimental validation.

The distinct Intelligence Index **v5.0** in the
[Sol release comparison](https://artificialanalysis.ai/models/releases/gpt-6-1-sol)
places max above xhigh under a different task mix and harness. It cannot fill
the missing coding effort. Astra/max remains an exceptional quality escalation,
with materially higher API cost in the checked coding comparison. Neither a
rounded composite difference nor a ranking proves universal task superiority
or statistical significance. Task-specific evidence still governs escalation.

Terra now has effort-specific Codex coding results. Its xhigh/max rounded tie,
with different measured API costs and active times, is no universal efficiency
guarantee. The provider's [model-selection guidance](https://developers.openai.com/api/docs/guides/model-selection)
positions Terra for writing, visual reasoning, defined computer-use outcomes
and scoped code fixes. That positioning and the
[Terra results](https://artificialanalysis.ai/models/releases/gpt-6-1-terra)
make it a candidate for representative same-input comparisons, not an adopted
replacement for Luna or Sol. Our precise effort and assignment choices remain
project judgment; neither provider positioning nor Intelligence results validate
each assignment row. Uncertain or consequential work retains the existing
Sol/escalation boundaries.

## Read the methodology with the result

replacing DeepSWE, Terminal-Bench **4.0**, and SWE-Atlas-QnA-AA. A composite can
hide weaknesses in repository changes, terminal work or repository Q&A. Do not
numerically mix this generation with v1.5 or infer an exact transition day from
its October release month.

use Codex **0.163.0** for Terra, **0.154.0** for Sol/Luna, and **0.153.4** for

evaluated model/effort/harness combinations, not model-only causal experiments
or current installed-client qualification. Exact individual run dates were not
established; a software release or audit-materialization date is not a run date.
API USD per task is not subscription usage. Active agent time excludes startup,
verifier and judge overhead. Rounded token/cost display changes alone establish
no model change, rerun or subscription-consumption change.

Intelligence uses Stirrup for FrontierCode 2.0 and mini-swe-agent for its terminal

## Pricing, caching, speed and API surfaces

[Codex pricing](https://learn.chatgpt.com/docs/pricing),
[API pricing](https://developers.openai.com/api/docs/pricing) and
[speed controls](https://learn.chatgpt.com/docs/agent-configuration/speed)
keep token USD rates, Codex credits and included-plan allowance distinct.
Benchmark API cost cannot be converted into weekly quota. Standard remains the
default unless the user chooses another speed. Terra supports Fast at the
existing billing multipliers; Ultrafast remains listed for Astra and Sol.
Billing multipliers are not measured speed gains; Ultra delegation is separate.

Current pricing expressly exempts Sol 6.1 **included subscription usage** from
the Work/Codex long-context surcharge, without expressly covering purchased
credits/PAYG. This is newly tracked, not a proven newly introduced policy.
The older Astra exemption was not reconfirmed; no opposite rule is inferred.
API long-context rules remain separate. This package exports no rate card,
account telemetry or quota conversion.

The [API changelog](https://developers.openai.com/api/docs/changelog) records
October 20's 12-hour caching option alongside the default 30-minute lifetime;
the [cache guide](https://developers.openai.com/api/docs/guides/prompt-caching)
distinguishes write and cached-read billing. October 22's Decisions API GA with
Luna adds shared-input caching and per-question inputs. These API-surface
features grant no Codex allowance, entitlement, delegation permission or new
model recommendation.
