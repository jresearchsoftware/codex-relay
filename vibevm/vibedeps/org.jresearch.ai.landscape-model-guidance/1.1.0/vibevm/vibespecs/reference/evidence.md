# Dated evidence for model selection

Package **1.1.0** reflects the November 17, 2026 advisory profiles and the
public evidence checked on **2026-11-22**.

## Coding Agent Index v2.1

The [Artificial Analysis methodology](https://artificialanalysis.ai/methodology/coding-agents-benchmarking)
documents FrontierCode-AA 2.0, Terminal-Bench 4.1 and SWE-Atlas-QnA-AA.
The first two replaced the versions used in v2.0. Compare results within the
same index version, harness, model and effort as appropriate. Cross-version
score differences cannot establish model improvements or regressions.

The [Codex comparison checked November 22](https://artificialanalysis.ai/agents/coding-agents/comparisons/codex-vs-grok-build)
includes GPT-6.2 Sol at Medium, High, Xhigh and Max. Among those rows, Xhigh
had the highest displayed composite, followed by Max, High and Medium.
GPT-6.2 Astra/Max scored above those four Sol rows. At matched Max effort,
GPT-6.2 Sol scored below GPT-6.1 Sol overall, with lower repository Q&A and
higher Terminal-Bench performance. No matched GPT-6.1 Sol/Medium Codex row
was checked for that comparison. These observations support testing escalation
on representative tasks. They do not predict cost against a subscription
allowance or quality on a particular task.

The [GPT-6.2 launch analysis](https://artificialanalysis.ai/articles/openai-has-the-2-model-in-the-intelligence-index-with-the-release-of-gpt-6-2-astra-and-gpt-6-2-sol)
compares Astra/Max and Sol/Max on Intelligence Index v5.0.1. That index measures
a different workload from the Codex coding-agent harness.

## Availability and cost

[OpenAI announced GPT-6.2 Sol and Astra on November 17](https://learn.chatgpt.com/docs/whats-new/gpt-62-astra-sol).
[Codex CLI 0.171.0](https://github.com/openai/codex/releases/tag/rust-v0.171.0),
released November 20, is this snapshot's first confirmed stable bundled
catalog with both models. Verify access in the actual client and account.
The catalog check establishes neither an older client floor nor successful
execution on a given plan or workspace.

[OpenAI Codex pricing](https://learn.chatgpt.com/docs/pricing) lists separate
Standard-speed credit rates. GPT-6.2 Sol retains the Sol 6.1 rates. GPT-6.2
Astra's published rates are lower than GPT-6 Astra's. Purchased-credit pricing
and benchmark API cost cannot derive included-plan allowance consumption.
Medium is the advisory default informed by practical GPT-6.1 allowance use.
The observation was uncontrolled and did not measure GPT-6.2 allowance ratios.
